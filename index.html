End-to-End Kubernetes CI/CD Pipeline

Using GitHub, Jenkins, Docker & Kubernetes

Project Overview

This project demonstrates an automated CI/CD pipeline where code is pushed to GitHub, built through Jenkins, packaged using Docker, stored in Docker Hub, and deployed automatically into Kubernetes.

Tools & Technologies

  • GitHub - Source Code Repository
  • Jenkins - Continuous Integration & Delivery
  • Docker - Containerization
  • Docker Hub - Image Registry
  • Kubernetes - Container Orchestration
  • Minikube - Local Kubernetes Cluster
  • AWS EC2 - Hosting Platform
